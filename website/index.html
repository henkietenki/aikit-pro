FAQ

Common questions

Which AI tools does AIKit Pro support?
A lot. The installer natively writes config files for: Claude Code (CLI + VS Code extension), Cursor (.cursorrules), Windsurf (.windsurfrules), Aider (.aider.conf.yml), and Void. The VS Code extension (Ctrl+Shift+A) works alongside Cline, Roo Code, Continue, GitHub Copilot (with Claude model), Supermaven, and Double.bot. For terminal users: Mentat and GPT-Engineer pick up the project config. For JetBrains: JetBrains AI Assistant, Cody, and CopilotForXcode all work with the same CLAUDE.md conventions.
Does this work with any project or language?
Yes. The skills work at the Claude Code level — they're not project-specific. You can use /code-review on a Python project today and a Node.js project tomorrow. The skills adapt to whatever codebase Claude Code is reading.
Do I need a Claude Code subscription too?
AIKit Pro configures Claude Code, Cursor, Windsurf, and Aider — you need whichever AI tool you plan to use. For Claude Code: a Claude Pro account or API key. For Cursor: a Cursor subscription. AIKit Pro is the expert configuration and skills layer that supercharges all of them.
What happens to the skills if I cancel?
Your local skills library and configuration remain on your machine. You just won't receive monthly updates to new skills, and your GitHub access to the private repo is removed. The skills you already have keep working.
How do monthly updates work?
The installer registers a scheduled task (Windows) or cron job (Mac/Linux) that runs on the 1st of each month. It pulls the latest skills via git and merges the CLAUDE.md template while preserving your personal Local Overrides section.
How is payment handled?
Payment is via SEPA bank transfer (EU accounts) or SWIFT (international). After you submit the form, you'll receive transfer details by email. GitHub repo access is granted once payment clears — usually within one business day. Cancel anytime by email; no lock-in.
